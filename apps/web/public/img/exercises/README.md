# Exercise pictures

One picture per exercise, ready for the future exercise library.

Rules:
- File name = the exercise slug, e.g. `bench-press.webp`.
- WebP, 640 x 640 pixels.
- Faceless matte 3D mannequin, with a lime light on the left and an orange light on the right, on a pure black background.
- Load them with `exerciseImage(slug)` from `src/lib/exerciseImage.js`.
